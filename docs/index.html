フロップ戦略（プリフロップの続き）

プリフロップでレイザー（アグレッサー）になった後、フロップで「打つ / 打たない / サイズ」をどう決めるか。鍵は ①誰がアグレッサーか ②ボードがどちらのレンジに有利か（レンジ有利）③ボードの濡れ具合（テクスチャー）の3つです。

この体系は「シングルレイズドポット・ヘッズアップ・100BB」を前提にした標準的なGTOベースの考え方です。マルチウェイや3betポットは別途調整が必要。
STEP 1自分はアグレッサー？ IP/OOP？
STEP 2このボードは自分とBBどちらのレンジに有利？
STEP 3テクスチャー（ドライ/ウェット）でサイズと頻度を決める
① 大原則：Cベットの3ステップ
1
レンジ有利を確認 — Aや高いカードが落ちたボードは、オープンレイザー（あなた）に有利。BBはA高を3betしてレンジから抜いている&コールレンジが弱いため。逆に 低・中連結ボード（中央 6〜9 中心） はBBのコールレンジにヒットしやすく不利。
2
テクスチャーでサイズを選ぶ — 乾いた(ドライ)A高など → 小さく(1/4〜1/3)を高頻度 湿った(ウェット)強いボード → 大きく(2/3〜ポット)を絞って 不利なボード → チェック多め
3
後のストリートを考える — IP（BTN/CO）はチェックが返ってきても後で取り返せるので幅広くCベット。OOP（SB/UTG-HJ vs BB）はチェックレンジを厚めに持ち、打つときは強めに。
② アグレッサー別のCベット指針（vs BB シングルレイズドポット）
あなた位置基本方針標準サイズ
BTN / COIP高頻度でCベット（60〜90%）。小サイズで広く圧をかけ、チェックは罠と弱いハンドのみ。1/3 中心
UTG / HJOOPレンジは強いがOOP。Aや K 高ボードは打ち、中低ボードはチェック多め。打つなら中〜大。1/3〜2/3 使い分け
SB（vs BB）OOPレンジ広い&OOP。チェックレンジを厚く。強いボード＆強い手で大きく。2/3 中心 + チェック
BB（コールした側）—基本はチェックして受ける（ドンクしない）。チェックレイズで強い手とドローを組む。chk / chk-raise

※ 頻度はGTOの目安。相手が降りやすい/コールしすぎなら、それぞれブラフ多め/バリュー多めにエクスプロイト。

③ ボードテクスチャー早見

ドライ A高（例 A72r）

レンジ有利が大きい。小サイズ(1/3)を超高頻度。ほぼ全レンジで打てる。

ドライ K/Q高（例 K83r）

同様にレイザー有利。小〜中サイズ高頻度。

ウェット高（例 KQ9ss・JT9）

強い手・強いドローで大サイズを絞って。エクイティが動くのでチェックも混ぜる。

中・低連結（例 765・984）

BB有利になりがち。チェック多め。打つならオーバーペア/強ドローで。

ペアボード（例 K72・882）

レンジ有利側が小サイズ高頻度。トリップス/オーバーペアは薄く長く。

モノトーン（例 ♠♠♠）

サイズ小さめ&頻度落とす。フラッシュ完成/A♠ブロッカーを意識。
④ ベットサイズの意味
サイズ使う場面狙い
1/4〜1/3レンジ有利なドライボードでレンジ全体を打つ安く広く。降ろす＋薄いバリュー
1/2標準。やや濡れたボードのバランスバリューとプロテクトの両立
2/3〜3/4濡れたボードで強い手/強ドロープロテクト＋大きなバリュー＋ブラフ圧
ポット〜オーバーナッツ寄り＆ドローを全力で否定最大バリュー。3バレル設計の入口
⑤ チェックする理由（迷ったら）

不利なボード

相手のレンジにヒットしている時は無理に打たない。

ポットコントロール

中途半端な強さ（セカンドペア等）は安く見たい。

トラップ

超強い手でアクションを誘う（ただしIPで相手がアグレッシブな時）。

レンジを守る

チェックレンジが弱いと相手に殴られる。強い手も一部チェックに残す。

📌 あなたのマイルール「迷ったらチェック」はOOPで特に有効。ただしIP・レンジ有利ボードでは「迷ったら小さくCベット」が基本。
